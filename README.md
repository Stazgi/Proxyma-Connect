# Proxyma Connect

Клиент для Android на базе открытого исходного кода [v2rayNG](https://github.com) с обновлённым интерфейсом. Поддерживает протоколы VLESS, VMess, Trojan, Shadowsocks, WireGuard и Xray-core.

## Скачать / Download

Актуальную подписанную версию APK можно скачать в разделе релизов этого репозитория:
👉 **[Скачать Proxyma Connect (Releases)](https://github.com)**

## Безопасность и открытый код

* Приложение собрано напрямую из публичного исходного кода с помощью GitHub Actions без сторонних трекеров и рекламных модулей.
* Сборка подписана официальным сертификатом проекта (`CN=Proxyma Connect, O=Proxyma, C=RU`).
* Проверить целостность и безопасность релизного файла можно через [VirusTotal](https://virustotal.com).
